# API de Administração: Gerenciamento de Conteúdo

Esta seção detalha os endpoints da API de Administração (\"Studio\") para gerenciar os diferentes tipos de conteúdo criados pelos usuários na plataforma \"Deeper\".

As funcionalidades incluem listagem irrestrita de conteúdo, edição de conteúdo de qualquer usuário, alteração de status (publicado, rascunho, arquivado, moderado), e exclusão.

## Módulos de Conteúdo Gerenciáveis:

1.  [**Administração de Artigos/Posts (`articles_admin_api.md`)**](./articles_admin_api.md):
    *   Endpoints para administradores gerenciarem o conteúdo do módulo `deeper_articles`.

2.  [**Administração de Eventos (`events_admin_api.md`)**](./events_admin_api.md):
    *   Endpoints para administradores gerenciarem o conteúdo do módulo `deeper_events`.

3.  [**Administração de Grupos (`groups_admin_api.md`)**](./groups_admin_api.md):
    *   Endpoints para administradores gerenciarem o conteúdo do módulo `deeper_groups`.

4.  [**Administração de Álbuns de Fotos (`photo_albums_admin_api.md`)**](./photo_albums_admin_api.md):
    *   Endpoints para administradores gerenciarem o conteúdo do módulo `deeper_photo_albums`.

5.  [**Administração de Enquetes (`polls_admin_api.md`)**](./polls_admin_api.md):
    *   Endpoints para administradores gerenciarem o conteúdo do módulo `deeper_polls`.

6.  [**Administração de Fóruns (`forums_admin_api.md`)**](./forums_admin_api.md):
    *   Endpoints para administradores gerenciarem fóruns, tópicos e posts do módulo `deeper_forums`.

*(Outros módulos de conteúdo serão adicionados aqui conforme são documentados).*

Cada arquivo detalhará os endpoints específicos, as permissões necessárias e as ações que podem ser realizadas.
